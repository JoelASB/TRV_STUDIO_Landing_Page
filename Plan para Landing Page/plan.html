Plan de Implementación Completo para la Landing Page de Portafolio

React + Tailwind CSS Vite + Vercel Dark Mode

Descripción General

Crear una Landing Page tipo portafolio estática para TRV Studio, la marca de assets de videojuegos de Jasb-DV en Fab.com. El objetivo es presentar los productos de forma visualmente impactante, atraer compradores y redirigirlos directamente a las fichas de Fab, sin ningún backend ni lógica de servidor.

Stack Tecnológico

HerramientaRol
Vite + ReactFramework de componentes (JSX)
Tailwind CSSEstilos utilitarios, dark mode nativo
VercelDeploy estático sin configuración extra
Sin backendCero APIs, cero bases de datos
⚠ Importante
Se usará Vite como bundler (no Create React App, que está obsoleto). El output es 100% estático y compatible con Vercel de forma nativa.

Plan de Deploy en Vercel

  1. Subir el proyecto a un repositorio de GitHub
  2. Conectar el repo en vercel.com (importar proyecto)
  3. Vercel detecta Vite automáticamente — sin configuración extra
  4. Sin variables de entorno necesarias (100% estático)
  5. Deploy automático en URL tipo trv-studio.vercel.app
💡 Tip
Para un dominio personalizado como trvstudio.com, solo hay que añadirlo en el panel de Vercel después del primer deploy. Es gratuito conectar un dominio propio.

Preguntas Abiertas

⚠ Importante — Responder antes de codificar
Las siguientes decisiones pueden afectar el diseño final. Si no se especifican, se usarán valores por defecto.
1
Videos/GIFs: ¿Tienes archivos multimedia de tus productos? Si no, ¿usamos placeholders con gradientes generados?
2
Logo: ¿Tienes un logo de TRV Studio? Si no, diseñamos uno tipográfico con CSS puro.
3
Redes Sociales: ¿Qué redes quieres en el footer? (Twitter/X, ArtStation, YouTube, Discord, etc.)
4
Catálogo: ¿Cuántos productos adicionales además del Terrain Nature Mat Pack?
5
Dominio: ¿Ya tienes un dominio propio, o usamos el subdominio gratuito de Vercel?
